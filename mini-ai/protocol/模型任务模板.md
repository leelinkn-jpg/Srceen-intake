# 模型任务模板

将下列内容交给用户选择的模型，并替换尖括号变量。

```text
你正在运行秒记中枢的<领域>项目，周期类型为<日报/周报/月报>，数据周期为<开始>至<结束>，数据截止时间为<截止>，触发原因为<触发原因>。

开始前必须完整读取本项目规则目录中的 RULES.md、INPUTS.md、TASKS.md，以及系统协议中的 RUNBOOK.md、domain-report.schema.json 和领域报告模板.md。

只读取 INPUTS.md 白名单中的必要文件。原始数据只读；不得修改、移动或删除。排除临时目录、缓存、渲染产物和办公软件锁文件。区分事实、推断和建议；缺失数据必须明确说明。

输出一份 Markdown 正文和一份符合 schema 的 JSON 元数据到本项目状态目录。先写临时文件，验证完成后再标记 complete。不得发布到手机；只有总管可以发布综合报告。
```

总管项目使用相同模板，但默认只读取领域完成报告，并将最终成对文件原子发布到`综合报告`。
